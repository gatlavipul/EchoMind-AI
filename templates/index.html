Integration Troubleshooting Guide

            Problem Translation
          


          

            Omi Wearable Ingestion:
            
What happened: Transcript ingestion requires either live webhook payloads, speech mic, or manual text paste.

            
Why it matters: Context cannot be retained without raw dialogue entering the pipeline.

            
How to fix: Configure OMI_API_KEY in .env for direct user sync, or post payloads to /api/ingest/omi.

            
Fallback status: Browser Web Speech API and manual paste function seamlessly without keys.

          


          

            Qdrant Cloud Vectors:
            
What happened: Vector memory requires an active Qdrant cluster with 384-dimensional cosine metric.

            
Why it matters: Cloud vector similarity allows rapid multi-thousand memory indexing.

            
How to fix: Create a cluster at cloud.qdrant.io, paste URL and API key into .env, and restart.

            
Fallback status: Local 384-dim semantic vector cosine search + SQLite lexical search actively running.

          


          

            Lyzr Agent Studio:
            
What happened: External agent reasoning requires LYZR_API_KEY and LYZR_AGENT_ID.

            
Why it matters: Live agent execution dispatches prompts to Lyzr Studio's inference endpoint.

            
How to fix: Create an agent at studio.lyzr.ai, configure LYZR_API_KEY and LYZR_AGENT_ID in .env.

            
Fallback status: Local autonomous multi-stage planner is verified and active.
